# aws-retail-data-analytics-platform
A cloud-based retail analytics project using AWS, SQL and Power BI to transform transaction data and uncover business insights.

## Project Overview

This project involves building a cloud-based retail data analytics platform using Amazon Web Services (AWS), SQL and Power BI.

Using the Online Retail dataset, containing 541,909 transaction records, the project explores how cloud technologies can be used to store, transform and analyse large volumes of retail data to generate meaningful business insights.

The platform uses Amazon S3 for data storage, AWS Glue Data Catalog for metadata management and Amazon Athena for SQL-based querying and data transformation. Power BI is used to visualise sales performance, product trends and customer behaviour.

## Project Objectives

* Build a cloud-based data storage and analytics environment using AWS.

* Transform raw retail transaction data into an analytics-ready Parquet dataset.

* Use SQL to investigate sales performance, customer behaviour and purchasing patterns.

* Perform data quality checks to identify missing values, duplicate records and transaction anomalies.

* Develop an interactive Power BI dashboard to communicate business insights.

## Technologies

* Amazon S3 – Cloud storage for raw and curated datasets.

* AWS Glue Data Catalog – Database and table metadata management.

* Amazon Athena – SQL querying and data transformation.

* SQL – Data analysis and validation.

* Apache Parquet – Columnar storage format for analytics.

* Microsoft Power BI – Data visualisation and dashboard development.
