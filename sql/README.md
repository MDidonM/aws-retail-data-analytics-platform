# SQL Analysis

This folder contains the SQL queries used to explore, transform and validate the Online Retail dataset using Amazon Athena.

## Analysis and transformations

- Sales performance and revenue analysis.
- Monthly sales trends.
- Product and customer purchasing behaviour.
- Transformation of raw CSV data into an analytics-ready Parquet dataset.
- Data quality checks, including missing customer IDs and cancellation records.

Individual SQL scripts will be added to document each stage of the project.
